# Raqamli malaka — landing (React + Vite + Tailwind)

Axion Studio uslubi + "Registon" palitrasi (lojuvard, firuza, oltin, fil suyagi).

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ papkaga
```

- Hero foni: `shaders/react` (Swirl, ChromaFlow, FlutedGlass, FilmGrain); GPU bo'lmasa statik gradient ko'rinadi.
- Ikonkalar: `lucide-react`.
- Rasmlar `public/img/` — platforma maketlarining skrinshotlari.

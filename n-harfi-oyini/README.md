# N harfi sayohati — 1-sinf uchun interaktiv o‘yin

**Fan:** Alifbe · **Mavzu:** 9-dars. [n] tovushi. N n harfi
**Qurilma:** kompyuter, interaktiv doska (planshetda ham ishlaydi)
**Davomiyligi:** 7–10 daqiqa

## Ishga tushirish
Butun `n-harfi-oyini` papkasini platformaga yuklang va `index.html` faylini oching. O‘yin oynani to‘liq egallaydi. Fullscreen tugmasi qo‘shilmagan: bu funksiya platformaning o‘zida bor. Internet bo‘lmasa ham ishlaydi, faqat shrift oddiy shriftga almashadi.

## Tuzilishi (darslik va taqdimot asosida)
Nunu ismli qahramon bolani 5 bekatli xarita bo‘ylab olib boradi. Topshiriqlar osondan qiyinga qarab joylashgan: **tovush → harf → yozish → bo‘g‘in → so‘z**.

| № | Bekat | Nima o‘rgatadi |
|---|-------|----------------|
| 1 | Harfli sharlar | N va n ni boshqa harflar (O, A, T) orasidan tanish |
| 2 | Harfni yoz | Barmoq bilan N va n ni yozish (“Ikki ustun oralab, qiya ustun tiragin”) |
| 3 | Tovush savati | So‘zda [n] tovushi bor-yo‘qligini eshitish (non, nok, banan… / olma, baliq…) |
| 4 | Harfni qo‘y | Tushib qolgan harfni qo‘yish: _on, o_a, a_or, o‘_, a_a, o_a (ota) |
| 5 | So‘z yasa | Bo‘g‘inlardan so‘z yig‘ish: o‿na, o‿ta, a‿na, a‿nor |

## Pedagogik va psixologik yondashuv
- **Jazo yo‘q:** vaqt chegarasi, “jon” yoki ball ayirish yo‘q. Xato bo‘lsa, Nunu muloyim maslahat beradi. Masalan, *ota* rasmiga **n** qo‘yilsa: “Unda «ona» bo‘lib qoladi. Rasmga qara!”
- **Bosqichma-bosqich yordam:** bola ikki marta adashsa yoki uzoq vaqt hech narsa qilmasa, to‘g‘ri javob yengil yaltirab ko‘rsatiladi.
- **Har bir to‘g‘ri javob rag‘batlantiriladi:** ovoz, maqtov (“Barakalla!”, “Ofarin!”), yulduzcha. Har bekatdan keyin bola katta yulduz oladi, oxirida medal.
- **Matnga kam tayanadi:** bola hali yaxshi o‘qimaydi, shuning uchun nima qilish kerakligi rasm, harakatlanuvchi nuqta va ishoralar bilan ko‘rsatiladi. O‘qituvchi ko‘rsatmani ovoz chiqarib o‘qib beradi.
- **Katta tugmalar:** doskada barmoq bilan bosish uchun qulay. Sudrab olib borish ham, oddiy bosish ham ishlaydi.

## Ovoz
Ovoz effektlari brauzerning o‘zida yaratiladi, audio fayllar kerak emas. Kompyuterda o‘zbekcha nutq ovozi o‘rnatilgan bo‘lsa, ko‘rsatmalar va so‘zlar avtomatik o‘qib beriladi va 🔊 tugmasi chiqadi. O‘rnatilmagan bo‘lsa, o‘yin ovozsiz ham to‘liq tushunarli. Yuqori o‘ng burchakdagi tugma ovozni o‘chiradi yoki yoqadi.
